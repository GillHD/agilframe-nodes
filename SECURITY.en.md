# AgilFrame security policy

[Русский](SECURITY.md) · **English**

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/GillHD/agilframe-core/security/advisories/new). Use public issues for bugs and feature requests.

Include the version or commit SHA, relevant configuration, scope of impact, and the minimum details needed to verify the report. Remove keys, tokens, participant data, and production addresses. Run checks only in environments you are authorized to access.

The maintainer uses the private report to ask questions, coordinate a fix, and publish an advisory. Follow the [security advisories](https://github.com/GillHD/agilframe-core/security/advisories) and update to versions that contain the fixes.
